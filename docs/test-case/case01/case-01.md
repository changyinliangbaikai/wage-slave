# 测试用例01

## 测试目标
自主完成Excel的处理任务

### 用例1
#### 任务提示词
将指定Excel(case01.xlsx),按照每一个sheet页拆分成独立的excel文件
并保存在测试目录下。

#### 预期结果
- [ ] Excel文件被成功拆分
- [ ] 每个sheet页对应一个独立的excel文件
- [ ] 文件名与sheet页名一致
- [ ] 文件内容正确


### 用例2
#### 任务提示词
将指定Excel(case01.xlsx),将第一个sheet按照B列中的内容进行拆分，将相同内容拆分到同一excel文件中，每个文件按照B列中的“拆分_内容”命名。
其余sheet页无需处理。
#### 预期结果
- [ ] Excel文件被成功拆分
- [ ] 每个拆分后的文件名与B列中的内容一致
- [ ] 文件内容正确
